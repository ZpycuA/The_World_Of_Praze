玩 法 概 述

《Asaka》是一款硬核 第三人称射击 · 搜索撤离 游戏。你将扮演队长，率领小队深入 尼珀斯尔工厂、边陲小镇、大陆银行·地下研究所 三片战区，搜索物资、击杀敌人、击败区域 BOSS，最后抵达撤离点安全撤出。

  • 单局目标：完成所有任务 + 从任意撤离点撤出，即为撤离成功；生命归零或倒地被击毙即失败。
  • 模式：单人 / 双人 / 三人小队，后两种模式下会有 AI 队友全程跟随，协助战斗与搜刮。
  • 难度：简单 / 普通 / 较难 / 噩梦，影响敌人血量、伤害、精度、反应以及精英怪数量。
  • 撤离：进入撤离点范围并清除附近敌人后，驻留 8 秒完成撤离。
基 础 机 制

生命与部位伤害 CORE

角色没有传统的“血条即生命”，而是由 七处身体部位 共同构成：头部、胸部、腹部、左右臂、左右腿。

  • 每个部位独立计算损伤，状态分为 正常 / 轻伤 / 中伤 / 重伤 / 断裂。
  • 腿部断裂会大幅降低移动速度；双臂断裂会显著增加射击散布。
  • 腹部重创会持续 流血，需要绷带或急救包止血。
  • 头部与胸部受致命伤时，会直接倒地。
在背包里可以随时查看每处部位的当前状态与百分比。

护甲系统 ARMOR

  • 分为 头部护甲 与 躯干护甲，等级 Lv0 ~ Lv8，减伤率 0% ~ 94%。
  • 护甲有独立的 耐久值，被击中会损耗；耐久归零后护甲失效。
  • 护甲耐久不能用时间自然恢复，必须用 修理包 / 陶瓷插板 / 纳米修复仪 修补。
  • 子弹有 穿透等级，穿透越高，护甲的有效减伤越低。

耦合系统 PRAZER ONLY

Prazer（兽耳亚种）角色拥有 耦合能——通过 P 空间借力所消耗的能量。

  • L1：仅对冷兵器有效，抵消 100% 动能，待机消耗 0.8/s。
  • L2：对冷兵器与热兵器有效，抵消 70% 动能，待机消耗 2.5/s。
  • L3：对所有武器（含激光）有效，抵消 50% 动能，待机消耗 5/s。
  • 受击时额外扣除耦合能；耦合耗尽后防护自动关闭。
  • 停止使用 1 秒后开始恢复；短时借力恢复 3/s，长时借力降至 1.5/s。
人类角色没有耦合系统，完全依赖护甲和肉体。

搜索与战利品 LOOT

  • 容器有稀有度分级：普通 → 精良 → 稀有 → 史诗 → 传说 → 遗物 → 金属 → INCREDIBLE。
  • 搜索需要 持续 2.5 秒，期间若移动或被击中将打断。
  • 尸体可以搜刮，敌人会掉落武器、护甲、弹药、配件与消耗品。
  • 背包、胸挂、口袋、安全箱共 31 格，拾取前需要规划空间。

P 空间事件 RANDOM

  • 物资空投：地图随机位置出现 3 个高价值容器，小地图红色标记。
  • P 空间波动：范围内敌人陷入混乱，Prazer 自身耦合能快速回复。
  • 沙尘暴：视野距离锐减，远程武器精度下降。
